# MATLAB figure: network topology and Hodge decomposition

The README contains one eight-panel figure, `hodge-workflow.png`, generated by [`generate_readme_figure.m`](generate_readme_figure.m). All data are deterministic and synthetic.

## Construction

Two concentric hexagons define a triangulated annulus with 12 vertices, 24 edges, and 12 triangular faces. The center is left unfilled. `Hodge_2Skeleton` constructs the simplices, and `Hodge_incidence` supplies the boundary matrices. The example remaps its cells 2 and 3 to cells 1 and 2 for `Hodge_decompose`.

The graph operator returned by `Hodge_laplacian` is `B1' * B1`. The full edge Hodge Laplacian is assembled as `B1' * B1 + B2 * B2'`. Their kernel dimensions are 13 and 1, respectively, as computed by `Hodge_ker`. Filling the 12 triangles removes 12 local cycle modes; one harmonic mode remains around the hole.

The input combines a gradient from deterministic node potentials, a curl from deterministic face potentials, and a harmonic eigenvector. Their squared norms are prescribed as 0.40, 0.35, and 0.25. `Hodge_decompose` recovers these components. The eigenvector sign is fixed to agree with counterclockwise circulation on the inner ring. All four flow panels share the same arrow-width scale. Pale shading indicates filled triangles; pale edges retain the support when a component has zero flow.

## Reproduction and verification

From the repository root in MATLAB:

```matlab
addpath(fullfile(pwd, 'assets', 'readme'));
generate_readme_figure;
```

The script writes the PNG and [`numerical-checks.json`](numerical-checks.json) to this folder, and saves the underlying arrays to `build/readme/figure-data.mat`.

Checked with MATLAB R2026b (26.2.0.3386108), using the existing package functions at source commit `6e95cf7ff09fb16a0c5ee4a25b8837b6ec3585cc`:

| Check | Result |
|---|---:|
| Boundary identity, `norm(B1 * B2, 'fro')` | 0 |
| Graph / full-complex kernel dimensions | 13 / 1 |
| Relative reconstruction error | 0 |
| Maximum error against known components | 1.88e-15 |
| Harmonic divergence norm | 5.05e-16 |
| Harmonic curl norm | 4.16e-15 |
| Maximum absolute pairwise component inner product | 7.15e-16 |
| Gradient / curl / harmonic energy fractions | 40% / 35% / 25% |

The same script also executes the README's five-node quick start: it yields one harmonic mode, zero reconstruction error, and harmonic constraint residuals below 6e-16. Floating-point residuals can vary across MATLAB versions and platforms.

These checks concern the two illustrated examples. The figure is an explanatory synthetic example, not a patient-data analysis or an evaluation of the paper-specific simulation studies.
